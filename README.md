# 📊 Sales & Revenue Analysis Dashboard

An interactive **Power BI dashboard** built to analyze sales performance, monitor revenue trends, and identify profitable products and regional sales patterns using retail sales data.

## 📌 Project Overview

The Sales & Revenue Analysis Dashboard transforms raw sales data into meaningful business insights through interactive visualizations and key performance indicators (KPIs).

The dashboard helps users understand overall business performance, compare product categories, analyze regional sales distribution, and track revenue trends over time. It supports data-driven decision-making by presenting important sales metrics in a clear and interactive format.

## 🎯 Project Objectives

- Analyze overall sales, revenue, and profit performance.
- Track monthly revenue trends and fluctuations.
- Identify top-performing products based on sales and revenue.
- Compare sales performance across product categories and regions.
- Enable interactive exploration of data using slicers and filters.

## ✨ Key Features

### 1. KPI Summary Cards
Provides a quick overview of essential business metrics:
- **Total Revenue:** Overall revenue generated from sales.
- **Total Quantity Sold:** Total number of units sold.
- **Total Profit:** Total profit generated from sales.

### 2. Monthly Revenue Trend Analysis
- Displays monthly revenue variations using a line chart.
- Helps identify revenue patterns and fluctuations over time.
- Supports analysis of business performance across different periods.

### 3. Product Performance Analysis
- Highlights top-performing products using bar charts.
- Enables comparisons based on sales volume and revenue.
- Helps identify products contributing significantly to overall performance.

### 4. Category-Wise Sales Analysis
Analyzes sales distribution across the following categories:
- Furniture
- Electronics
- Office Supplies
- Accessories

### 5. Regional Sales Analysis
Compares sales performance across four regions:
- North
- South
- East
- West

### 6. Interactive Slicers and Filters
- Date-range selection for time-based analysis.
- Regional filtering to explore location-specific performance.
- Interactive visuals that update based on user selections.

## 🛠️ Tools and Technologies

## 🚀 How to Use

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop).
3. Open the `Sales_Revenue_Analysis.pbix` file.
4. If required, update the dataset path in Power BI.
5. Refresh the data to load the latest available dataset.
6. Explore the dashboard using the interactive slicers and visualizations.
